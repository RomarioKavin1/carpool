## What this does not show

- **The name's Hedera record is the same account as the manifest's signed
  fallback** (`0.0.10475801`, as instructed). The transfer alone therefore cannot
  distinguish "paid from the name" from "paid the fallback"; `payoutVia`, the
  registry log line and the live binding check are what show the name was used.
  A rotation to a different account, live, is not shown.
- `payoutVia` is read from the saved `/state`, not re-derived live: the registry
  was local and has been stopped.
- One sale, one name, Sepolia only.
